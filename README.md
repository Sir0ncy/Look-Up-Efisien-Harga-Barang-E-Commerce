# Look-Up-Efisien-Harga-Barang-E-Commerce
Dengan menggunakan algoritma Insertion Sort untuk mengurutkan data barang berdasarkan harga barang, kemudian dikombinasikan dengan Binary Search untuk mempercepat proses pencarian daftar barang yang sudah terurut. Diharapkan program dapat mencari barang yang sesuai dengan cepat serta efisien.
